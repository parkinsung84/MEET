# 위치기반서비스사업 신고 준비 (초안)

> 2025-10-01 시행 위치정보법 개정 기준. 신고는 **사업자(운영자) 본인**이 공동인증서·간편인증으로 로그인해 제출해야 합니다.
> 제출 전 [위치정보지원센터](https://www.lbsc.kr/)(무료 상담)에 이 서비스가 신고 대상인지, 어떤 유형인지 한 번 확인하는 것을 권장합니다.

## 1. 어떤 신고를 하나요?

| 운영자 | 해야 할 일 |
| --- | --- |
| **소상공인 또는 1인 창조기업** | 신고 없이 사업 시작 가능. 단, **사업 개시일부터 1개월 이내**에 "소상공인등의 위치기반서비스사업 신고"(상호, 주된 사무소 소재지, 사업의 종류 및 내용) |
| 그 외 (법인 규모가 큰 경우 등) | 사업 시작 **전에** "위치기반서비스사업 신고" (사업용 주요 설비 등 포함) |

- 관할: **방송미디어통신위원회**
- 신청: [정부24 — 소상공인등의 위치기반서비스사업 신고](https://www.gov.kr/mw/AA020InfoCappView.do?HighCtgCD=A09001&CappBizCD=15701000086) 또는 [전자민원센터](https://www.emsit.go.kr/)
- 처리: 검토·수리까지 최대 2주 정도
- 먼저 필요한 것: **사업자등록** (소상공인·1인 창조기업 여부도 이것으로 판단)

## 2. 신고서에 적을 내용 (복사해서 쓰세요)

**상호**: `[사업자등록증의 상호]`

**주된 사무소 소재지**: `[사업자등록증의 사업장 주소]`

**사업의 종류**: 개인위치정보를 대상으로 하는 위치기반서비스사업

**사업의 내용**:

> 택시 합승(동승) 이용자 연결 서비스 "MEET"(웹/모바일 웹앱).
> 이용자가 기기의 현재 위치를 사용해 출발지를 입력하면(선택 기능), 좌표를 주소로 변환해 출발지로 표시하며 좌표는 저장하지 않습니다.
> 이용자가 선택한 출발지·도착지(장소명·좌표)를 바탕으로 가까운 합승방을 검색하고, 경로 중간 하차 매칭과 예상 요금 분담을 계산합니다.
> 같은 합승의 멤버에게 만남 장소를 안내하고, 이용자가 만든 안심 공유 링크를 받은 사람에게 합승 경로(출발지·도착지 이름)와 택시 차량번호를 보여줍니다. 실시간 위치 추적은 하지 않습니다.
> 위치정보는 위치정보사업자(기기 운영체제·브라우저의 위치 서비스, 네이버클라우드 지도 API)로부터 제공받아 이용합니다.

## 3. 신고와 별개로 지켜야 할 의무 (앱에 반영 상태)

| 의무 | 상태 |
| --- | --- |
| 위치기반서비스 이용약관 게시·동의 | ✅ `public/legal/location.html`, 가입 시 필수 동의 (운영자 정보 채우기 필요) |
| 개인위치정보 이용·제공 사실 확인자료 자동 기록·보관 (위치정보법 제16조) | ✅ `src/location-log.js` — 이용·제공할 때마다 일시·목적·제공받는 자 기록, 1년 보관, 본인 열람(내 정보 → 위치정보 이용 내역) |
| 위치정보관리책임자 지정 | ❌ 약관에 이름·연락처 기재 필요 |
| 개인위치정보 이용 목적 달성 후 파기 | ✅ 현재 위치 좌표는 저장하지 않음, 탈퇴 시 익명화 |
